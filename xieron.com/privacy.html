Privacy Policy

SECTION 01

Data Collection

To operate, the bot stores limited non-personal IDs: server, user, channel and role IDs, plus per-server settings. Message content is analysed in memory for spam/phishing detection and is not stored permanently. Data at rest is described as encrypted (AES-256) with TLS in transit.

SECTION 02

Use of Data

Data is used only for core features, moderation actions, stability/latency improvements, and debugging/support. The service states it never sells or shares data with third parties.

SECTION 03

Message Monitoring & Processing

Messages are checked in real time for spam/flooding, blacklisted words or links, and scam/invite abuse. Processing is volatile (in-memory); only moderation-action metadata is retained.

SECTION 04

Access to Data

Only a server's owners/authorized admins can manage its data. Developers may access data strictly for bug fixing, support or feature work.

SECTION 05

Data Storage & Retention

Server data is kept while the bot is present. Dashboard activity logs are described as capped at the latest 1,000 entries for up to 30 days. After removal there is a 7-day grace period, then deletion; owners can also request immediate deletion.

SECTION 06

Data Deletion Procedure

A verified server owner can request full deletion by providing the Server ID and proof of ownership via the support server.

SECTION 07

Contact & Privacy Support

Privacy questions and deletion requests go through the official Discord support server (discord.gg/xieron).
